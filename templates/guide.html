01 — What is PROJECT VOID?

PROJECT VOID lets you hide files inside audio that sounds like nature — birdsong, crickets, ocean ambience, midnight pond recordings. Anyone who listens to the audio hears natural sounds. Only someone with the right key can extract the hidden data.

The platform is built on three pillars:

  • Steganography Engine — Embed any file (documents, images, video) inside WAV audio using LSB encoding with advanced scatter techniques. The output is indistinguishable from a nature recording.
  • Sovereign Hashing (Al-Jabr 286) — A custom 286-bit hash algorithm that replaces standard SHA-256. Because it's 30 bits longer than standard, forensic scanners looking for 256-bit patterns pass right over it.
  • Ghost Internet (Beehive Mesh) — An acoustic peer-to-peer network where nodes discover each other using 432 Hz frequency pulses. No internet connection required.
In plain terms: You put a secret file into an audio file. The audio sounds normal. Nobody knows the file is there. Only your key can get it back out.

03 — How to Hide Data (Encode)

This is the core feature — embedding a file inside an audio carrier so nobody knows it is there.

1Go to the Engine and click the Encode tab.
2Upload a carrier audio file (a WAV file). This is the "container" your data will hide inside. You can generate one using the carrier generator if you do not have one.
3Upload the payload file — this is the file you want to hide. It can be any type: documents, images, video, archives.
4Choose your LSB Depth:
• Depth 1 — Maximum stealth. Smaller capacity but virtually undetectable.
• Depth 2 — Maximum capacity. Holds more data with slightly less stealth.
5Choose a Scatter Mode:
• Linear — Standard sequential embedding.
• Vortex — 432 Hz harmonic spiral pattern (recommended for biophony carriers).
• Chirp Sync — Synchronizes data placement to insect chirp peaks.
• Fly Jitter — Random temporal scatter for maximum forensic evasion.
6Enter a passphrase (encryption key). You will need this same passphrase to decode later. Without it, the data cannot be extracted.
7Click Encode and wait for processing. The output is a WAV file that sounds like the original carrier — but now contains your hidden data.
8Download the output file from the Files tab.
Important: Keep your passphrase safe. Without it, nobody (including you) can extract the hidden data. There is no password recovery.

04 — How to Extract Data (Decode)

Retrieve a hidden file from a stego audio carrier.

1Go to the Engine and click the Decode tab.
2Upload the stego WAV file — the audio that contains hidden data.
3Enter the same passphrase that was used during encoding.
4Click Decode. The system will extract, decrypt, and decompress the hidden file.
5Download the recovered file from the Files tab. It will be identical to the original.
Integrity check: Every encoded file includes an MD5 checksum. If the audio has been tampered with, the decode will report a checksum mismatch.

14 — Security & Encryption

PROJECT VOID uses its own encryption stack instead of relying on standard libraries. Here is how each layer works:

Al-Jabr 286 (Password & Data Hashing)

A custom 286-bit hash algorithm. Standard forensic tools search for 256-bit patterns (SHA-256). Because Al-Jabr 286 is 30 bits longer, these tools pass over it as if it were random noise. The extra 30 bits are derived from a 7-layer process inspired by mathematical root structures.

ChaCha20 Encryption (Headers & Messages)

Every encoded file has a 64-byte header encrypted with ChaCha20. This header contains the filename, data size, MD5 checksum, and a random nonce. Without the correct key, the header is indecipherable — and without the header, the embedded data cannot be located or extracted.

ChaCha20-Poly1305 (Messenger)

Messenger messages use authenticated encryption (ChaCha20-Poly1305). Each conversation has its own randomly generated 256-bit encryption key. Messages are encrypted before storage and decrypted only when delivered to an authorized member.

Dual Compression

Before embedding, data is compressed using both zlib (level 9) and lzma (preset 9). The system automatically selects whichever produces the smaller output. This maximizes the amount of data that fits in a given carrier.

Anti-Forensic Techniques

  • Ghost Header — The encrypted header can be placed at a randomized offset, not at byte 0.
  • Dither Mask — Applies noise-like patterns to mask the statistical signature of embedded data.
  • Vortex Scatter — Distributes data bits in a 432 Hz harmonic spiral rather than sequentially.

15 — Frequently Asked Questions

Is PROJECT VOID free?
The software is free and open source. The Pirate Build blueprints for the physical hardware are also free. The Sovereign Edition (pre-built hardware node) costs £25,000.
What file types can I hide?
Any file type — documents, images, video, archives, databases, executables. The system does not care about the content. It compresses, encrypts, and embeds the raw bytes.
How large can the hidden file be?
Up to approximately 1 GB, depending on the carrier length and LSB depth. A 5-hour Midnight Pond carrier at LSB-2 can hold about 1.8 GB. The Journalism Port is capped at 50 MB for simplicity.
Can someone detect the hidden data?
Standard forensic tools search for 256-bit hash patterns. Al-Jabr 286 uses a 286-bit hash that does not match any known pattern. The audio output passes spectral analysis as natural ambient sound. However, no steganography system is 100% undetectable under all conditions.
What audio format is used?
16-bit PCM WAV at 44,100 Hz sample rate. This is an uncompressed format that preserves every bit of data. Compressed formats (MP3, AAC) would destroy the embedded data.
Do I need the physical hardware?
No. The software runs entirely in the browser and on the server. The 4000-Series Sovereign Node is optional hardware for people who want a dedicated, off-grid, tamper-resistant installation.
What happens if I forget my passphrase?
The data cannot be recovered. There is no password reset or backdoor. This is by design — if you cannot decrypt it, nobody can.
Is the Messenger truly encrypted?
Yes. Every message is encrypted with ChaCha20-Poly1305 before it reaches the database. Each conversation has a unique random encryption key. The database only ever stores ciphertext — plaintext never touches disk.
Can I share the output audio over the internet?
Yes. The stego WAV file can be emailed, uploaded, shared via messaging apps, or even broadcast over radio. As long as the recipient has the original WAV file (not a compressed version), they can decode it.
What is the 432 Hz frequency?
432 Hz is the base frequency used throughout PROJECT VOID — for carrier generation, mesh handshakes, and Vortex scatter patterns. It was chosen because it sits in a natural resonance band and creates harmonics that blend with environmental audio.
