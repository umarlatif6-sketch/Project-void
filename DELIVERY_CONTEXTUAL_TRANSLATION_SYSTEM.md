## PART 4: THE CONTEXTUAL TRANSLATION ENGINE

### Architecture

The Contextual Translation Engine is a Python system with four core components:

1. **Domain Dictionaries** — Three dictionaries (Finance, Water, Ocean) with term definitions and codons
2. **Domain Detector** — Identifies domain context from text
3. **Translation Layer** — Maps terms to principles and translates across domains
4. **Unified Decision Generator** — Combines findings across domains into coherent strategy

### Core Functions

#### Function 1: Domain Detection

```python
detect_domain(context: str) -> Domain
```

Analyzes context text and identifies which domain it belongs to using keyword matching.

**Example:**
```
Input: "The InteleTravel agent's commission flow accelerates when customer resonance is high"
Output: Domain.FINANCE
Reasoning: Keywords "commission", "flow", "accelerates" indicate Finance domain
```

#### Function 2: Term Translation

```python
translate_term(term: str, source_domain: Domain, target_domains: List[Domain]) -> TranslationResult
```

Translates a term from source domain to target domains through underlying principles.

**Example:**
```
Input: translate_term("flow", Domain.FINANCE, [Domain.WATER, Domain.OCEAN])
Output: 
  - Original: flow (finance)
  - Principle: FLOW (◆→)
  - Translations: {
      WATER: "flow",
      OCEAN: "flow"
    }
  - Resonance: 66.67%
  - Impedance: 10.00%
```

#### Function 3: Ambiguity Resolution

```python
resolve_ambiguity(term: str, context: str) -> TranslationResult
```

Resolves linguistic ambiguity by detecting domain and translating term.

**Example:**
```
Input: 
  - Term: "flow"
  - Context: "The customer journey flow slows when booking interface is complex"
Output:
  - Detected Domain: WATER
  - Principle: FLOW (◆→)
  - Meaning: Liquid displacement through channels
```

#### Function 4: Unified Decision Generation
