# Project Void Song Pack

## Contents
- **Keep Intent Intact v2 (92 BPM)**
  - `project_void_keep_intent_intact_v2_instrumental.wav/mp3`: Full instrumental track.
  - `project_void_keep_intent_intact_v2_demo_song.mp3`: Demo version with vocal cue.
  - `project_void_keep_intent_intact_v2_stem_drums.wav`: Drum stems.
  - `project_void_keep_intent_intact_v2_stem_bass.wav`: Bass stems.
  - `project_void_keep_intent_intact_v2_stem_pad.wav`: Pad stems.
  - `project_void_keep_intent_intact_v2_click.wav`: 4-count click track.

- **Thread Under Pressure (138 BPM)**
  - `project_void_thread_under_pressure_instrumental.wav/mp3`: Full instrumental track.
  - `project_void_thread_under_pressure_vocals.wav`: Raw vocal hook.
  - `project_void_thread_under_pressure_demo_song.mp3`: Demo version with vocal hook.

## Usage
Run `./build_project_void_song_pack.sh` to regenerate assets.
