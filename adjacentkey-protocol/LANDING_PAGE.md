# AdjacentKey Protocol: Landing Page

## What is AdjacentKey Protocol?
A new standard for human-to-AI and AI-to-AI communication, turning keyboard "errors" into a robust, intent-aware language layer. Every keystroke is a signal, not just a mistake.

- Encode/decode text using QWERTY adjacency (left/right, multi-jump, custom layouts coming soon)
- CLI, Python API, and agent integration
- User profiling: adaptive decoding for every unique user/agent
- Designed for privacy, resilience, and creativity

## Why use it?
- Make your AI/agent systems more human, error-tolerant, and intent-aware
- Build privacy-preserving, steganographic, or signature-based communication
- Integrate with any Python, CLI, or agent ecosystem

## Quickstart

From the Project VOID repository:

```bash
pip install -e ./adjacentkey-protocol
adjacentkey encode "what am i saying how are you" --direction right
adjacentkey decode "ejsy sm o dsuomh jpe str upi movr" --direction right
```

## Features
- QWERTY adjacency encoding/decoding
- CLI and Python API
- User profiling (adaptive, coming soon)
- Modular, extensible, and open
