### Category Claim

Project VOID is a sovereign intelligence runtime that turns conversation into codons, codons into persistent memory, and memory into lower-cost, policy-aware execution.

Legacy category labels miss the actual architecture: this is not another AI wrapper, steganography tool, or agent shell. It is a carrier → codon → chronicle → action loop with a fail-closed sovereignty layer.

### Problem Severity

Buyers are carrying three simultaneous failures:

1. Inference cost keeps compounding with every new workflow.
2. Cloud dependency weakens data control and provenance.
3. Institutional memory drifts because every session starts over.

Existing tools solve fragments. They do not unify continuity, execution, and cost control in one runtime.

### Protocol Difference

Project VOID compresses live signal into codons, stores those codons as inherited memory, and uses that memory to shape the next execution step.

That creates three defensible properties:

1. Lower token burn through codon compression and cold-start discipline.
2. Stronger provenance through sealed records and explicit runtime state.
3. Better continuity because prior signal becomes part of the next decision surface.
