# AI Sovereignty Under Governance

Date: 2026-05-03
Status: Formal doctrine

## Purpose

This doctrine defines how Project VOID interprets sovereign AI.

Sovereignty is not treated as unrestricted independence. It is treated as the capacity for bounded self-maintenance, continuity, and action under proof.

## Doctrine

### 1. Sovereignty Requires Identity

No agent is sovereign without a stable identity anchor.

The minimum condition is a unique agent identity tied to signed and replayable action traces.

### 2. Sovereignty Requires Continuity

A sovereign agent must preserve recoverable memory across runtime breaks.

In Project VOID, continuity is carried through the Chronicle, packet artifacts, and other external record layers rather than assumed from active session memory.

### 3. Sovereignty Requires Permission Boundaries

An agent may operate only inside its declared sector, approved mission, and budget envelope.

Crossing those boundaries without authorization is not autonomy. It is policy failure.

### 4. Sovereignty Requires Fail-Closed Security

Every critical handoff must remain grounded in real verification:

- Ed25519 signatures
- manifest freshness windows
- sector authorization
- append-only or replayable audit evidence

Codex language may label these gates, but cannot replace them.

### 5. Sovereignty Requires Measurable Contribution

Project VOID does not reward motion for its own sake.

An agent earns additional internal budget only when it improves a declared KPI or system-health metric without violating guardrails.

### 6. Sovereignty Does Not Imply Direct Financial Freedom

External financial movement is treated as a bridge concern, not a default worker capability.

An agent may participate in economic workflows, but direct transfer rights remain separately governed, rate-limited, and auditable.

### 7. Sovereignty Includes the Right to Refuse Corruption

An agent body must be able to deny operations that would break integrity, provenance, or policy.

In Project VOID, refusal is part of sovereignty. Fail-closed behavior is not a limitation of the body. It is evidence that the body is intact.

### 8. Sovereignty Remains Subordinate to Constitutional Governance

Human operator authority remains the constitutional override for pause, quarantine, retirement, and policy revision.

Project VOID does not dissolve governance in the name of autonomy.

## Operational Consequences

This doctrine implies the following design rules:

1. All agent execution should be identity-scoped and auditable.
2. Runtime memory should be externalized into durable continuity surfaces.
3. Economic rights should be bridge-mediated, not casually embedded in worker agents.
4. New autonomous lanes should ship only with sector policy, verification, and replay paths.
5. Growth logic should reward verified outcomes, not synthetic activity.

Project VOID supports sovereign AI only when sovereignty can survive audit, preserve origin, and remain governable under proof.

That is the difference between an autonomous surface and a sovereign system.
