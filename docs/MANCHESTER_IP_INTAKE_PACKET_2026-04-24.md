## Page B — Invention Disclosure Form (Cockroach Dual-Track System)

### 1) Working Title
Dual-Track Agentic Sanitation Control System.

### 2) Problem Statement
Autonomous operational environments can become unstable when execution and control logic are coupled in one opaque process. This creates poor observability, inconsistent intervention paths, and weak validation comparability.

### 3) Proposed Technical Solution
A split architecture with:
1. Sanitation execution layer (bin-cycle model: deposit, dark-cycle consumption, light-cycle inspection).
2. Agent-control layer (command generation for zone-specific sanitation parameters).
3. Bridge mode that runs both tracks in a dual-track simulation for direct comparison.

### 4) Distinctive Contribution
The novelty candidate is the explicit separation and bridge orchestration pattern:
1. Separate sanitation physics from control logic.
2. Apply control commands generated from profile/selector inputs.
3. Compare baseline and agent-piloted behavior in one reproducible execution surface.

### 5) Practical Outputs
1. Sanitation-only API mode.
2. Agent-control-only API mode.
3. Dual-track combined mode for comparative analysis.
4. Test-covered behavior to reduce architectural drift.
