# Buyer Target Sheet Template (30 Targets)

Use this template to run a disciplined 14-day buyer outreach sprint.

## Columns (copy into a spreadsheet)

1. Priority Tier (T1/T2/T3)
2. Company
3. Buyer Type (Strategic / PE-backed / Acqui-hire)
4. Segment Fit (AI Ops / Security / Dev Platform / Consulting / Vertical SaaS)
5. Decision Maker Name
6. Decision Maker Role
7. Corp Dev Contact
8. Intro Path (Warm / Cold Email / LinkedIn / Advisor)
9. Strategic Fit Score (1-5)
10. Speed-to-Close Score (1-5)
11. Budget Signal (Low/Medium/High)
12. Last Funding / Cash Signal
13. Outreach Date
14. Outreach Channel
15. Response Status (No Reply / Replied / Meeting / Diligence / LOI)
16. Next Step Date
17. Objection Pattern
18. Proposed Structure (Cash / Cash+Earnout / License+Buyout)
19. Price Range Discussed
20. Probability to Close (0-100%)
21. Notes

## Scoring Rules

- Strategic Fit Score
  - 5: Immediate integration path and clear roadmap compression
  - 3: Partial fit, requires narrative work
  - 1: Weak alignment

- Speed-to-Close Score
  - 5: Founder-led buyer or fast corp dev motion
  - 3: Normal procurement cycle
  - 1: Heavy procurement / low urgency

- Priority Formula
  - Priority Score = (Strategic Fit x 2) + Speed-to-Close + Budget Signal Weight
  - Budget Signal Weight: Low=1, Medium=2, High=3

## Outreach Sequence Template

1. Day 1: Send warm intros to top 6 Tier-1 targets
2. Day 2: Send direct emails to next 6 Tier-1 targets
3. Day 3: LinkedIn follow-up to all non-responders
4. Day 4-5: Book and run first discovery calls
5. Day 6-7: Send deal-structure options to engaged buyers
6. Day 8-10: Run diligence previews with top 3 buyers
7. Day 11-14: Push LOI decisions
