# ORYX Company Blueprint

ORYX is positioned as a separate company linked to Project VOID through optional APIs, shared lore pipelines, and selected intelligence systems.

## Separation Rules
- ORYX must be operable without Project VOID.
- Project VOID may provide optional world seeds, lore packets, or agent policies.
- Brand, pricing, and creator onboarding should be managed independently.

## Product Thesis
- Sell a creator engine, not only a single game.
- Make world creation cheaper than heavyweight proprietary platforms.
- Start with simulation-first products: agents, quests, factions, resources, and persistent states.
- Expand later into cinematic tools, multiplayer orchestration, and creator marketplaces.

## Revenue Shape
- Free prototype tier for solo builders
- Paid studio tier for persistent hosted worlds
- Marketplace fee for creator assets, quests, and world templates
- Optional enterprise tier for branded universes and private deployments

## Link to Project VOID
- Optional import of codex themes, signals, or world seeds
- Optional export of ORYX telemetry back into Project VOID research
- No hard runtime dependency required
