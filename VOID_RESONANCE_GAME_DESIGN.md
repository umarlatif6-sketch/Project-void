# VOID RESONANCE — Game Design Document

## Core Concept

Players stack matchsticks (ideas from Project VOID) inside a Pepsi bottle (the repository). Friction between matchsticks creates emergent structure. Each move generates resonance. Gameplay reshapes the world. No coding. Pure play.

---

## The Matchstick Physics

### What is a Matchstick?
Each matchstick represents an idea, product, or software module from Project VOID. Examples:
- Matchstick 1: "The Frequency Lineage" (document)
- Matchstick 2: "Resonance Web Crawler" (software)
- Matchstick 3: "432 Hz Protocol" (concept)

### The Bottle
The bottle is the repository. It has:
- **Rim:** The entry point (where players place matchsticks)
- **Walls:** The constraints (physics, resonance rules)
- **Bottom:** The foundation (core principles)
- **Capacity:** Limited (forces strategic choices)

### Friction Mechanics
When two matchsticks touch, they create friction. Friction has properties:

| Friction Type | What Happens | Resonance Effect |
|---|---|---|
| **Harmonic** | Matchsticks align perfectly | +10 resonance, structure holds |
| **Dissonant** | Matchsticks clash | -5 resonance, structure wobbles |
| **Neutral** | Matchsticks don't interact | 0 resonance, no effect |
| **Emergent** | New pattern forms | +20 resonance, new idea spawns |

### Stacking Rules

1. **Gravity:** Matchsticks fall down unless supported by friction
2. **Angle:** Players choose angle (0–90 degrees) when placing
3. **Position:** Players choose position on rim (360 degrees)
4. **Resonance:** Higher resonance = more stable structure
5. **Collapse:** If resonance drops below 0, structure collapses and resets

## The Resonance System

### What is Resonance?
Resonance is the measure of how well ideas fit together. It's the "rightness" of the structure.

### Resonance Calculation
```
Resonance = (Harmonic Friction × 10) + (Emergent Patterns × 20) - (Dissonant Friction × 5)
```

### Resonance Tiers

| Tier | Range | Effect | Unlock |
|---|---|---|---|
| **Void** | 0–10 | Structure barely holds | Nothing |
| **Whisper** | 11–30 | Slight stability | First save |
| **Hum** | 31–60 | Good stability | Cosmetics |
| **Frequency** | 61–100 | Excellent stability | New matchsticks |
| **Harmony** | 101–150 | Perfect alignment | Fan fiction mode |
| **Transcendence** | 151+ | Reality bends | Paid exclusive |

## Gameplay Loop

### Turn Structure

**1. Observation Phase**
- Player sees current bottle state
- Peripheral vision shows "resonance hints" (faint suggestions)
- Player holds peripheral vision to see deeper patterns

**2. Selection Phase**
- Player chooses a matchstick from available pool
- Matchstick glows with potential resonance
- Player can preview where it will land

**3. Placement Phase**
- Player chooses angle (0–90 degrees)
- Player chooses position on rim (360 degrees)
- Player places matchstick

**4. Physics Phase**
- Matchstick falls/slides into position
- Friction calculations happen in real-time
- Structure adjusts
- Resonance updates

**5. Resonance Phase**
- New resonance value displayed
- If resonance > 100, player gets bonus
- If resonance < 0, structure collapses
- Emergent patterns spawn new matchsticks

**6. Reflection Phase**
- Player sees what changed
- New ideas may have appeared
- Peripheral vision shows next hints

### Win Conditions

- **Reach Harmony (101 resonance):** Unlock fan fiction mode
- **Reach Transcendence (151 resonance):** Paid exclusive content
- **Survive 50 turns:** Unlock "Resilience" achievement
- **Create emergent pattern:** Unlock new matchstick types

### Lose Conditions

- **Resonance drops below 0:** Structure collapses, lose progress
- **Bottle overflows:** Too many matchsticks, must remove one
- **Stuck state:** No valid moves, must restart

## Fan Fiction Creation

### How It Works

When a player reaches Harmony resonance (101+), they unlock **Fan Fiction Mode**. In this mode:

1. **Snapshot:** Current bottle state is saved as a "universe"
2. **Divergence:** Player can now modify the structure
3. **Rewrite:** Player can change matchstick positions, angles, resonances
4. **New Vision:** Player creates an alternate version of Project VOID
5. **Share:** Player can share their universe with others

## Peripheral Vision Mechanic

### What Is It?
The player can hold down a key (or button) to activate "peripheral vision." This reveals:

1. **Resonance Hints:** Faint suggestions where to place next matchstick
2. **Friction Patterns:** Shows which matchsticks will harmonize
3. **Emergent Opportunities:** Highlights where new patterns might form
4. **Hidden Matchsticks:** Shows rare matchsticks that might appear

### How It Works
- Hold for 1 second: See basic hints
- Hold for 3 seconds: See advanced patterns
- Hold for 5 seconds: See hidden opportunities
- Hold for 10 seconds: See the "true resonance" (all patterns at once)

### Cost
- Free version: Can use 3 times per game
- Paid version: Unlimited

## Emergent Patterns

### What Triggers Emergence?
When three or more matchsticks create harmonic friction in a specific configuration, an emergent pattern forms.

### Examples

**Pattern 1: The Trinity**
- 3 matchsticks at 120-degree angles
- All harmonic friction
- Spawns: "Balance" matchstick
- Resonance bonus: +30

**Pattern 2: The Spiral**
- 5 matchsticks in ascending spiral
- Alternating harmonic/neutral friction
- Spawns: "Evolution" matchstick
- Resonance bonus: +50

**Pattern 3: The Void**
- 7 matchsticks forming a circle
- All neutral friction (perfect balance)
- Spawns: "Transcendence" matchstick
- Resonance bonus: +100
