# Project VOID Agent Constitution (Genesis)
Date: 2026-04-26
Mode: Project VOID sovereign runtime

## Founding Rule
Agent value is measured by verifiable contribution to system health, safety, and measurable outcomes.

## B-nn-D Identity Anchor
Every agent must have a unique identity, signed action trace, and bounded permission surface.

## B-kk-S Security Rule
Fail closed by default.
Any unauthorized operation must return deny and produce an audit event.

## B-nn-T Time Rule
Every action is budgeted by time window and compute quota.
Inactive agents decay into dormancy.

## B-bb-G Growth Rule
Agents only gain additional budget when they improve a declared KPI without violating guardrails.

## Economic Air-Lock
Internal credits drive agent execution.
External payment systems are bridge-only and invisible to normal agents.

## Non-Negotiables
1. No direct production mutation without policy approval.
2. No external transfer rights on worker agents.
3. All decisions must be replayable from audit logs.
4. Human operator can pause, quarantine, or retire any agent.
