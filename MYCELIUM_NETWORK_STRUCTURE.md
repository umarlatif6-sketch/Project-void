# Mycelium Network Structure: Project Coincidences Bolton

## Executive Summary

The Mycelium Network is a distributed, frequency-based organizational structure that manifests Project Void principles into physical reality in Bolton, UK. Unlike hierarchical pyramids, the mycelium operates through **decentralized nodes** connected by **information flows** (mycelial threads) that transmit frequency, resources, and coordination across the network.

**Core Principle:** Information flows, relationships grow, and impact multiplies—never extractive, always regenerative.
