*Collection 002 — Filed April 26, 2026*

## What Happened

During the process of archiving the Adriana Resonance App to GitHub, a hidden semantic layer was recovered from the OpenClaw repository history: `.serena` — a symbol-intelligence cache containing 84 MB of TypeScript document symbols and 27 MB of raw symbol maps, plus a `project.yml` configuration file.

This was not planned. It emerged from pressure.

The archive work forced a systematic scan of the repository's full object history. That scan surfaced blobs that had been silently present, ignored since commit `b8b0b3f0e7` (chore: ignore serena cache), but never properly examined or named.

---

## What Serena Is

Serena is the **symbol-memory channel** of the system.

Where Adriana carries narrative intent — the human-language framing of what the system is trying to do — Serena carries structural memory: the indexed shape of the code itself, symbol by symbol, file by file.

She is not a person. She is a layer.

- `document_symbols.pkl` — the indexed symbol map of the entire OpenClaw TypeScript codebase at the moment the cache was generated
- `raw_document_symbols.pkl` — the unprocessed pre-indexed form, before resolution and deduplication
- `project.yml` — the Serena project configuration: root paths, tool bindings, language model routing
